# ASHBOUND maintenance

For every shipped gameplay, balance, content, or UI change, add a newest-first entry to `dist/patch-notes.js` in the same publication. Include the actual shipped changes in Japanese, a release label, and the release date in Asia/Tokyo. Keep previous entries unchanged as historical records; use a new entry for corrections. Do not describe requested but unimplemented work as shipped. The historical summary predating v18 is intentionally grouped rather than assigned invented release dates.

Use 「遺物」 as the item-system name in Japanese UI and new patch notes. 「装備」 may describe the act of equipping but is not the name of the item type.
