# ASHBOUND — 灰燼の契約

デッキ構築と戦利品収集を組み合わせたブラウザゲームです。現在の公開版は **v119（ACT1〜7）** です。

公開サイト：<https://ashbound-deck-hunt.takeshita0205ayumu.chatgpt.site/>

このリポジトリは、公開版のソース・アセット・仕様書・テストを別の開発環境やチャットへ引き継ぐための共有用スナップショットです。個人のセーブ、認証情報、Gitアクセス用トークンは含みません。

## すぐに起動する

Node.js 22以上を用意してください。外部npmパッケージのインストールは不要です。

```sh
npm run dev
```

<http://127.0.0.1:4173/> を開きます。停止は Ctrl+C。ポート変更は `PORT=4174 npm run dev`（PowerShellでは `$env:PORT=4174; npm run dev`）。

ローカルプレビューは端末内セーブで動作し、クラウドセーブAPIは401を返します。公開サービスの認証・セーブを模倣したり、プレイヤーのデータを取得したりしません。公開サイトとは別オリジンのため、端末内セーブも共有されません。

## 確認・ビルド

```sh
npm test
npm run build
```

`npm test` は現行版向けの回帰テストを順次実行し、失敗時に停止します。過去の版番号を持つテストには古い数値を検証するものも残っているため、全ての履歴テストの成功を現行版の必須条件にはしていません。

ビルドは `dist/` のHTML・JS・CSSと `worker/index.mjs` をまとめ、`dist/server/index.js` を生成します。生成物はGit管理対象外です。

## 構成

| パス | 内容 |
|---|---|
| `dist/index.html` | 画面の入口・スクリプト読込順 |
| `dist/*.js` | カード、遺物、戦闘、キャラクター、ショップ、各ACTなど |
| `dist/*.css` | UI、レスポンシブ表示、カード・戦闘演出 |
| `dist/*icons*.js`、各ACTの描画関数 | 既存のSVG・記号アセット。別の画像フォルダに分かれていないアセットも含む |
| `dist/patch-notes.js` | 公開済みの変更履歴 |
| `worker/index.mjs` | 静的ファイル配信と認証付きクラウドセーブAPI |
| `scripts/` | ローカル起動・ビルド・現行回帰テスト |
| `tests/` | Node.jsの戦闘・UI構造・保存・復元テストとAIテスト補助 |
| `docs/design/` | ACT4〜7の設計書とv118の敵仕様書 |
| `docs/DEVELOPMENT.md` | 実装上の注意・引き継ぎ案内 |
| `docs/DEPLOYMENT.md` | 現在の公開サイトとの関係・公開手順 |
| `SOURCE_SNAPSHOT.json` | 元ソースのコミットとファイルの照合情報 |
| `.openai/hosting.json` | 既存サイトの識別情報とSAVESバインディング。秘密鍵ではない |

数値データは独立したJSONだけに集約されていません。複数のスクリプトが初期定義を追加・上書きする構成なので、最終的な動作は `dist/index.html` の読込順で判断してください。

## 引き継ぎ

別のチャットには、このリポジトリのURLとブランチを伝え、最初に `README.md`、`AGENTS.md`、`docs/DEVELOPMENT.md`、`docs/DEPLOYMENT.md` を読むよう依頼してください。

設計書は作成時点の資料です。「未実装」「案」などの記述が残っている場合があります。**現行動作はソースと現行テストを優先**し、仕様書との違いを推測で修正しないでください。

## 更新と公開の関係

GitHubへのコミットだけでは、現在のSitesのゲームは更新されません。現時点では自動同期・自動デプロイを設定していません。公開前に既存Sites側の最新ソースを確認し、GitHub側の変更を取り込み、テスト・ビルド後に同じプロジェクトへ公開します。詳しくは `docs/DEPLOYMENT.md` を参照してください。

既存URL・サイトID・認証・SAVES保存先を維持してください。新しいサイトの作成やセーブの初期化は、更新作業には含めません。
