# ACT4「寄生樹海」改定の実装範囲

## 通常戦

- 通常戦の1〜3戦目は単体4編成から重複なしで抽選する。4戦目以降は2体4編成を一巡ごとにシャッフルし、巡の境目で同じ編成が連続しない。
- 弱プールで寄生花を引かなければ、強プールの初めの2戦のいずれかで出現する。強敵とボスは通常戦の回数に含めない。

## 万骸の母樹

- 開幕は母樹のみ。2ターン目に獣2体を召喚する。母樹は6ターン周期で行動し、永花により強化行動で芽吹きを消費しない。攻撃で実際にHPが減ると1ヒットにつき芽吹きが1減る。
- 復活した獣は最大HPで戻り、復活の次の敵ターンから①を行う。HPは従来どおり母樹230、獣各40。
- 刻印は山札に残る未刻印のカード個体から重複なしで抽選する。寄生2はカードの使用ごとに浸食2を付与し、同名の別カードには伝播しない。浸食はプレイヤーターン終了時と敵ターン終了時に現在HPと比較する。敵の参照行動には敵ターン開始時点の浸食を使用する。
- 更新前から進行中のボス戦は旧行動で続行する。刻印や抽選袋は探索データに保存される。

## 通常敵と強敵

- 宿り蛾、寄生花、枝憑き猿の行動を改定。根憑き甲虫は開幕ブロックと既存の行動を継続。
- 花骸鹿の「花殻の崩落」、接ぎ木の群体の「つながる根」、種宿しの苗床の「寄生孵化」を実装した。
- 苗床②は種嚢・幼虫が生存している場合も攻撃し、召喚だけ省く。⑤の判定は苗床の行動時点で行い、その後に種嚢が行動する。孵化した幼虫は次の敵ターンに初回行動を行う。
- 開始済みの通常戦・強敵戦も旧行動を継続する。既存の調整設定は、新しい行動表にも存在する項目を適用する。遭遇の重みは一巡内の出現順に適用する。
