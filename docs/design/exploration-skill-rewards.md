# 強敵報酬の探索技能

強敵を撃破すると、現在の技能を除く同じ探索者の3技能から1つを選べる。変更をスキップして現在の技能を維持できる。潜在カードとポーションは既存の報酬手順で受け取る。選択結果は現在の探索に保存され、次の探索は初期技能から始まる。

- 放浪は複数タイプのカードを使うと、そのカードに含まれる各タイプの初回を消費する。
- 頂点捕食者は最大HPを端数切り捨てで5%（最低1）増やす。現在HPはそのまま。
- 超進化は進化先が存在する範囲で適用し、退化は従来どおり1段階進める。
- フォーチューンハンドはドロー後の実際の手札コストで判定し、左から順に既存の自動プレイ処理で解決する。
