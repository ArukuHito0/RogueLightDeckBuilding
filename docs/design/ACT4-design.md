作成日：2026年11月12日（日本時間）  
対象基盤：ASHBOUND v114  
文書状態：実装前の設計。サイトへの実装・公開は未実施。

## 1. 目的と決定事項

ACT4のテーマは「寄生」。寄生植物に身体を侵食された生物と、その生物を苗床に広がる樹海を舞台にする。

プレイヤーが体験する中心的な判断は、敵を倒す、芽吹きを削って次の行動を弱める、ブロックして自分のビルドを成長させる、の配分である。行動に固有名は付けず、効果と数値だけを表示する。

### 決定事項と設計上の補完

| 区分 | 内容 |
|---|---|
| 会話で確定 | 寄生のテーマ、芽吹きへの改名、攻撃ダメージでHPが減るたび芽吹き1減少、取得量は初期案から+2～3、最終敵名、行動名を付けない |
| 基礎案を継承 | HP、基本行動、芽吹きの強化係数、強化行動後の全消費、ボスの本体撃破による勝利 |
| 本書の実装補完案 | 同時行動順、スタン時の芽吹き保持、再生時の状態初期化、召喚上限、保存項目、表示・テスト要件 |
| 未検証 | 実戦バランス、実ソースとの接続方法、画面上の寸法。以下の数値は初期実装値であり、調整済みの保証ではない |

母蛾の召喚数を「芽吹き÷2の切り上げ」にする案は会話中の提案で、明示的な承認はない。本書では削った成果が出る補完案として採用候補を明記する。

## 3. 共通ギミック「芽吹き」

### 表示用説明

> 特定の行動を強化する。攻撃ダメージによってHPが減少するたびに1減少する。強化行動の解決後、全て消費する。

### 判定仕様

- 敵が保持する0以上の整数。通常のターン終了では減らない。
- ダメージ量ではなく、攻撃の各ヒットで実際にHPが減った回数を数える。
- 1回の攻撃でHPが1減っても30減っても芽吹きは1減少。
- ブロックを一部貫通してHPが減った場合は1減少。全て防いだ場合は減少しない。
- 多段攻撃は各ヒットで独立判定。全体攻撃は各対象で独立判定。
- 毒、裂傷の追加ダメージ、棘、茨の盾、焼身など、非攻撃ダメージでは減少しない。
- HP喪失、最大HP変更、回復、自死処理では減少しない。
- 芽吹き0でも元の行動を行う。強化部分だけが0になる。
- 強化行動の解決開始時に芽吹きをスナップショットし、解決後に全消費する。
- スタン等で強化行動自体が実行されなければ、芽吹きは消費しない（補完案）。

| 例 | 芽吹きの減少 |
|---|---:|
| 単発20ダメージでHP減少 | 1 |
| 3回攻撃の全ヒットでHP減少 | 3 |
| 3回攻撃のうち2回はブロックで完全防御 | 1 |
| 攻撃1回でHP減少後、裂傷が発動 | 1 |
| 毒だけでHP減少 | 0 |

### 取得量

| 取得する敵 | 初期案 | 最終取得量 | 増加幅 |
|---|---:|---:|---:|
| 宿り蛾 | 2 | 4 | +2 |
| 寄生花 | 2 | 4 | +2 |
| 花骸鹿 | 4 | 7 | +3 |
| 種宿しの女王 | 3 | 5 | +2 |
| 母樹の各宿主 | 3 | 5 | +2 |

「取得」は現在値への加算。付与前に残っていた芽吹きを指定値に置き換えない。

## 4. 通常敵

各敵の行動は①から開始し、最後まで進むと①へ戻る。初期芽吹きは0。HP以外の初期状態は表に記載があるものだけ付与する。

| 名前 | HP | 初期状態 | 行動順 |
|---|---:|---|---|
| 宿り蛾 | 42 | — | ①芽吹き4 → ②6＋芽吹き×4ダメージ、芽吹きを全消費 → ③4ダメージ×2 |
| 根憑き甲虫 | 58 | ブロック12 | ①8ダメージ → ②12ブロック → ③5ダメージ×2 |
| 寄生花 | 46 | — | ①芽吹き4 → ②生存中の敵全体を4＋芽吹き×4回復、芽吹きを全消費 → ③7ダメージ |
| 枝憑き猿 | 48 | — | ①4ダメージ×3 → ②8ブロック → ③14ダメージ |

- 宿り蛾の最大強化時の単発ダメージは22。
- 寄生花の最大強化時の回復量は20。自身を含み、最大HPを超えない。芽吹き0でも4回復。
- 根憑き甲虫にはブロック保持を付けない。開幕12ブロックも通常の敵ターン開始時の消失規則に従う。
- 寄生花は死んだ獣を苗床にして咲く植物、枝憑き猿は蔓に操られる獣として表現する。

### 遭遇構成の補完案

最初の通常戦闘3回は単体で基本を提示し、以降は2体編成から抽選する。強敵・ボス・召喚敵を通常敵プールに混ぜない。

| 編成 | 主な判断 |
|---|---|
| 宿り蛾＋枝憑き猿 | 次の強化攻撃を削るか、今攻撃する敵を倒すか |
| 根憑き甲虫＋寄生花 | 防御の厚い敵を攻めるか、回復役から倒すか |
| 宿り蛾＋寄生花 | 攻撃と回復のどちらの芽吹きを優先して削るか |
| 根憑き甲虫＋枝憑き猿 | 芽吹きを持たない敵に、通常の火力・防御を配分する |

## 5. 強敵

### 5.1 花骸鹿（かがいじか）

HP110。角と眼窩から寄生植物が伸びた鹿。単体で出現する。

| 順番 | 行動 |
|---:|---|
| 1 | 芽吹き7を得る |
| 2 | 6ダメージ×2 |
| 3 | 10＋芽吹き×5ダメージ。その後、芽吹きを全消費 |
| 4 | 12ブロック、筋力2 |

芽吹きを削らない場合、初回の強化攻撃は45ダメージ。以降は筋力も加算される。取得直後と次の攻撃後の2ターンで、芽吹きを削るか自身を強化するか判断する。

### 5.2 接ぎ木の群体

本体HP76、枝HP24×2。複数の獣を根で接続した集合体。

| 対象 | 行動 |
|---|---|
| 本体 | ①8ダメージ → ②12ブロック → ③14ダメージ。その行動後、倒れている枝を1本再生 |
| 枝 | 毎回5ダメージ |

- 本体の3番目の行動が正常に完了したときだけ再生する。
- 再生HPは24。再生時は状態効果・ブロック・筋力を初期化する。
- 再生した枝は同じ敵フェーズでは行動しない。
- 両枝が倒れていれば固定の枝スロット順で1本再生する。
- 本体撃破で戦闘終了。残った枝は撃破扱いにせず、追加の撃破効果を発生させない。
- 枝を実際に撃破したときは通常の撃破効果を適用する。再生後に再撃破した場合も1回として扱う。

### 5.3 種宿しの女王

HP95。腹部を寄生植物の種床にされた虫。

| 順番 | 行動 |
|---:|---|
| 1 | 芽吹き5を得る |
| 2 | 4ダメージ×3 |
| 3 | 芽吹きに応じて種宿しの幼虫を召喚。その後、芽吹きを全消費 |
| 4 | 12ダメージ |

種宿しの幼虫はHP12、毎回4ダメージ。同時に存在できる幼虫は3体まで。

**召喚数の補完案：** `min(ceil(芽吹き / 2), 空き幼虫枠数)`。

| 芽吹き | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|---:|
| 空き枠が3ある場合の召喚数 | 0 | 1 | 1 | 2 | 2 | 3 |

- 召喚した敵は同じ敵フェーズには行動しない。
- 空き枠がなく召喚0体でも、実行済みの強化行動として芽吹きを消費する。
- 女王撃破後も幼虫が残っていれば戦闘は継続する（補完案）。

## 6. ボス「万骸の母樹」

多数の生物を根で取り込み、その骸を養分に育った巨木。本体と2体の宿主が同時に出現する。

| 対象 | HP | 役割 |
|---|---:|---|
| 万骸の母樹 | 230 | 戦闘の本体。宿主に芽吹きを与え、倒れた宿主を再生する |
| 根に繋がれた獣 | 40 | 旧「爪の宿主」。芽吹きで攻撃を強化する |
| 花に喰われた獣 | 40 | 旧「腹の宿主」。芽吹きで母樹への回復を強化する |

### 共同行動周期

| 順番 | 母樹 | 根に繋がれた獣 | 花に喰われた獣 |
|---:|---|---|---|
| 1 | 生存している各宿主に芽吹き5 | 独立行動なし | 独立行動なし |
| 2 | 8ダメージ | 6＋自身の芽吹き×4ダメージ、芽吹きを全消費 | 独立行動なし |
| 3 | 5ダメージ×2 | 独立行動なし | 母樹を自身の芽吹き×6回復、芽吹きを全消費 |
| 4 | 倒れた宿主を1体、HP40で再生 | 独立行動なし | 独立行動なし |

- 最大強化時、根に繋がれた獣は26ダメージ、花に喰われた獣は母樹を30回復。
- 両宿主が倒れている場合は、根に繋がれた獣を優先して再生する。
- 再生時は芽吹き0、他の状態効果・ブロック・筋力も初期値。再生したフェーズには追加行動しない。
- 宿主には通常通り攻撃・毒・裂傷・スタン等が通る。
- HP半分での強制状態解除、無敵、フェーズ移行は設けない。
- 母樹撃破時に勝利する。残った宿主は撃破扱いにせず消滅する。

### スタンと実行順の補完案

- 母樹と宿主は別の対象。母樹へのスタンで宿主の行動まで停止させない。
- 母樹の周期は敵フェーズごとに共通で1つ進む。スタンした対象の処理だけを飛ばす。
- 順番2は「根に繋がれた獣の攻撃 → 生存確認 → 母樹の攻撃」、順番3は「花に喰われた獣の回復 → 母樹の攻撃」。
- 反撃で母樹が死亡した場合、その時点で戦闘終了し、残りの敵処理を行わない。
- 順番1で母樹がスタンしていれば、宿主への芽吹き付与は発生しない。
- 順番2・3で対象宿主がスタンしていれば、その効果も芽吹き消費も発生しない。

## 7. カードプールとの関係

| ビルド | ACT4での役割 |
|---|---|
| 多段攻撃・筋力 | 芽吹きを複数減らしながら宿主を撃破する |
| 狩人の裂傷 | 元の攻撃ヒットで芽吹きを削り、裂傷でHPを追加で削る。裂傷自体では芽吹きは減らない |
| 毒 | ブロックを無視して撃破を狙う。芽吹きは減らないため、別途防御や攻撃を配分する |
| 全体攻撃 | 複数の敵・宿主の芽吹きを同時に削る |
| 防御・反撃 | 敵の強化行動を受け止めつつHPを削る。反撃自体で芽吹きを減らさない |
| 進化・特殊カード | 敵の準備ターンに育て、強化攻撃までに火力や防御を整える |
| フォールド・ポーカー | 自動使用を含む攻撃ヒットで芽吹きを削る。手動使用かどうかは判定条件にしない |

既存カードID・既存効果を変更せず、ACT4専用対策カードの取得を必須にしない。

## 8. UI・予告

- 敵の状態欄へ「芽吹き N」を常時表示し、ホバー・タップで説明を確認できるようにする。
- 予告は現在の芽吹き、筋力、脱力、脆弱等を反映した最終値を表示する。攻撃命中で芽吹きが減った直後に更新する。
- 行動名は表示しない。「22」「4×3」「20回復」「芽吹き+4」「幼虫×3」などのアイコン・効果表記にする。
- 宿主と母樹の予告は各対象の上へ分離し、攻撃主体と回復主体を明確にする。
- スタン時は実行しない予告として表示し、実際の処理と一致させる。
- 図鑑の状態説明に芽吹きを追加する。既存の検索・タブ・倍率設定を維持する。
- 芽吹きの視覚表現は茎・芽・花を基本にする。装飾によってHP・予告・状態表示を隠さない。

### 攻撃判定の接続

共通ダメージ処理で「攻撃フラグ」と「実HP減少量」を確認する。カード名やダメージ数値だけで攻撃と推定しない。

```js
// 概念コード。既存関数の引数・戻り値に合わせて接続する。
const hpBefore = target.hp;
resolveDamage(target, amount, options);
if (options.attack === true && target.hp < hpBefore) {
  target.bud = Math.max(0, (target.bud ?? 0) - 1);
}
```

実処理ではHP減少確定直後、派生する裂傷・反撃・死亡処理より前に一度だけ判定する。多段攻撃の外側でまとめて1回判定しない。予告更新は副作用の解決後に行う。

### 敵フェーズ

1. フェーズ開始時に行動対象の一覧を確定する。
2. 行動直前に生存・スタン・戦闘終了状態を確認する。
3. 強化行動なら芽吹きを読み取り、効果を解決し、全消費する。
4. 攻撃の各ヒット間に死亡・勝利・敗北を判定する。
5. 行動終了処理、再生、次の予告更新を行う。

フェーズ中の新規召喚・再生対象は開始時の行動一覧に入れない。リロードで同じフェーズの行動を重複実行しないよう、既存の敵フェーズ保存方式に合わせる。

### 状態データ候補

| 項目 | 用途 |
|---|---|
| enemy.bud | 芽吹きの現在値。未定義は0 |
| enemy.act4Kind | 固定内部ID。表示名変更と独立させる |
| enemy.groupId / role | 本体・枝・宿主の所属と役割 |
| enemy.actionStep | 通常の行動周期。既存方式を優先 |
| encounter.phase | 母樹の共同行動周期1～4 |
| encounter.slots | 枝・宿主の固定枠と生死・再生対象を保持 |

倒れた対象を敵配列から削除する基盤なら、再生に必要なスロット情報を遭遇側へ保持する。配列インデックスだけで親子関係を表現しない。

## 11. 検証項目

### 芽吹き

- 単発、多段、全体攻撃で、HP減少ヒット数と減少量が一致する。
- 完全ブロックでは減らず、一部貫通では1減る。
- 毒・裂傷・棘・茨の盾・焼身・HP喪失では減らない。
- 自動プレイされた攻撃でも減り、0未満にならない。
- 行動前の減少が予告へ即反映される。
- 強化行動後だけ全消費し、スタンで不実行なら保持する。

### 敵・召喚・ボス

- 各行動周期、筋力加算、回復上限、芽吹き0時の効果が正しい。
- 母蛾の芽吹き0～5、幼虫の既存数0～3の全組み合わせで召喚数が正しい。
- 召喚・再生した対象が同フェーズに行動しない。
- 枝は3番目の行動完了時だけ1本再生し、本体撃破で勝利する。
- 母樹の宿主ごとの芽吹きとスタンが分離される。
- 母樹撃破で即終了し、宿主だけの撃破では勝利しない。
- 再生対象の優先順位と状態初期化が正しい。
- 反撃・毒・多段攻撃中の死亡で処理が重複しない。

### 保存・回帰

- ACT3クリアによる解放とACT4選択が再起動後も保持される。
- ACT4戦闘中の芽吹き・行動順・幼虫・枝・宿主を保存復元できる。
- v114のACT1～3進行中セーブを読み込める。

## 12. バランス評価の重点

取得量を増やしたため、前案よりも未対処時の攻撃・回復が大きい。特に宿り蛾22、寄生花20回復、花骸鹿45、母樹の宿主26／30回復を初期検証の重点とする。
