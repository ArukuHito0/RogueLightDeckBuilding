作成日：2026年11月13日（日本時間）

## 1. テーマとプレイ体験

舞台案：黄金の廃市。テーマは強欲・略奪・奪還。

敵がゴールド・HP・エナジーを奪い、それを戦力へ変える。撃破で資源を取り戻す。共通のステージ操作は追加せず、敵の能力で体験を作る。

| 資源 | 中心となる体験 |
|---|---|
| ゴールド | 敵が初期資金・生成資金を使う前に倒し、報酬を増やす。供給役を倒して資金切れを狙う |
| HP | 被害を与えた敵を倒し、HPを取り返して立て直す |
| エナジー | 敵に蓄積された手数を取り返し、残った敵への攻撃につなげる |

行動には固有名を付けず、番号と効果で記載する。能力名は維持する。

## 2. 共通仕様

### 2.1 ゴールド

- 指定された攻撃行動で、プレイヤーからゴールドを奪う。HPダメージは不要で、全てブロックされても奪取する。
- 多段攻撃でも、奪取は攻撃行動1回につき1回。スタンなどで行動自体を実行しなければ奪わない。
- 所持金不足なら現在所持している分だけ奪い、所持金を負数にしない。
- 敵は保持ゴールドを消費して強化行動を行う。不足時は行動表の代替行動を実行し、ゴールドを消費しない。
- ゴールドによる強化は原則、その行動限り。永続筋力を共通効果として追加しない。
- 敵には初期所持・生成・プレイヤーからの奪取という資金源がある。

| 資金の出所 | 消費後の扱い | 撃破時 |
|---|---|---|
| 初期所持 | 報酬としては失われる | 未消費分のみ獲得 |
| 生成・供給 | 報酬としては失われる | 未消費分のみ獲得 |
| プレイヤーから奪取 | 返却権は残る | 消費済みも含め累計奪取額を全額返却 |

消費順は、初期所持・生成分を先、奪取分を後とする。撃破時の返却額は「未消費の初期所持・生成分＋プレイヤーからの累計奪取額」。保持残高を丸ごと加算すると、未消費の奪取分を二重に返すため注意する。通常戦闘報酬とは別枠。

### 2.2 HP・貯蔵血

- 能力「血の徴収」を持つ敵は、自身の攻撃で実際に減らしたプレイヤーHPを貯蔵血として得る。
- 例：12ダメージを8ブロックで防いだ場合、貯蔵血は4増える。追加でHPを奪う処理はない。
- 貯蔵血は行動で消費できる。現在の貯蔵量と累計奪取HPを別管理する。
- 撃破時は消費済みも含め累計奪取HPを回復。最大HPを超えて回復しない。
- 他の敵による被害や、プレイヤー自身のHP消費は貯蔵しない。

### 2.3 エナジー

- 指定行動で、次のプレイヤーターンの回復分からエナジー1を奪う予約を行う。
- 奪取は一時的な回復分の減少で、以後の基礎回復量を永続的には減らさない。
- 実際に差し引けた量だけ敵の保持エナジーへ加算する。予約時点では保持量を増やさない。
- 保持エナジーは消費せず蓄積し、自動返却もしない。複数回奪えば保持量が増える。
- 撃破時は残っている保持量をプレイヤーへ返却する。
- プレイヤーターン中の返却は現在エナジーへ加算。敵フェーズ・終了処理中の返却は、次のプレイヤーターンの通常回復に加算する。
- 奪取予約元が実際の奪取前に死亡した場合は、予約を取り消す案とする。
- 複数予約時も回復分を負数にせず、敵の行動順で解決する。返却エナジーは奪取対象の通常回復分に含めない。

### 2.4 その他

- 通常の敵ブロックは自身の行動前に消失し、保持しない。
- 通常敵・強敵は全生存敵撃破で勝利。ボス戦は黄金卿撃破で勝利。
- 返却は敵1体につき一度だけ。攻撃・毒・裂傷・反撃など、撃破手段を問わない。
- 保持量、強化量、次の消費・供給先、撃破時の返却量を予告・説明で確認できるようにする。

## 3. 通常敵

### 3.1 金歯の追い剥ぎ

HP48／初期所持20G。

| 順番 | 行動 |
|---|---|
| ① | 8ダメージ・15G奪取 |
| ② | 15G消費して7×2。不足なら8ダメージ |
| ③ | 6ブロック |

ゴールド奪取・消費の基本役。1周期の最大供給15G・消費15G。

### 3.2 金庫背負い

HP64／初期所持40G。

| 順番 | 行動 |
|---|---|
| ① | 20G消費して18ブロック。不足なら6ブロック |
| ② | 12ダメージ・20G奪取 |
| ③ | 5×2 |

資金を防御へ変える敵。1周期の最大供給20G・消費20G。

### 3.3 買収の祈祷師

HP46／初期所持30G。

| 順番 | 行動 |
|---|---|
| ① | 15G消費して、自身以外の生存敵全体に10ブロック。対象不在または資金不足なら、消費せず自身に5ブロック |
| ② | 9ダメージ・30G奪取 |
| ③ | 15G消費して、生存敵全体をHP6回復。不足なら6ダメージ |

通常の2体編成では、1周期の最大供給30G・消費30G。

### 3.4 血袋の亡者

HP58／初期貯蔵血0。

| 順番 | 行動 |
|---|---|
| ① | 10ダメージ |
| ② | 貯蔵血を最大8消費して、8＋消費量のブロック |
| ③ | 4×3 |

能力「血の徴収」を持つ。貯蔵血0なら②は8ブロック。

### 3.5 灯盗みの小鬼

HP44／初期保持エナジー0。

| 順番 | 行動 |
|---|---|
| ① | 次のプレイヤーターンのエナジーを1奪う |
| ② | 4×2 |
| ③ | 10ダメージ |

能力「盗んだ灯」：保持エナジー1につき筋力＋1。現在保持量に連動する補正で、毎ターン永続加算する処理ではない。各ヒットに筋力を加える。

### 3.6 贋金鋳造師

HP46／初期所持0G／生成総額上限80G（仮）。

| 順番 | 行動 |
|---|---|
| ① | 20G生成し、自身以外の生存敵1体へ供給 |
| ② | 8ダメージ・自身に6ブロック |
| ③ | 20G生成し、自身以外の生存敵1体へ供給 |

- 供給対象はゴールドを消費する敵に限定し、現在所持額が最も少ない敵を選ぶ。同額なら並び順。
- 対象不在・生成上限到達時は、①③を自身に8ブロックへ置き換える。
- 生成分は直接送金し、自身には蓄積しない。生成累計は消費・撃破でリセットしない。
- 送金先は受領分を通常の保持ゴールドとして消費でき、未消費分を撃破時に落とす。
- 単独戦闘では供給を学べないため、導入の単体抽選からは除外する案。

## 4. 通常戦闘の編成

最初の通常戦闘3回は固定順にしない。金歯の追い剥ぎ・金庫背負い・買収の祈祷師・血袋の亡者・灯盗みの小鬼から、ランダムで1体。等確率を初期案とする。

4回目以降は以下の2体編成を等確率で抽選する案。

| 編成 | 主な特徴 |
|---|---|
| 金歯の追い剥ぎ＋金庫背負い | 攻撃と防御へゴールドを使用 |
| 金庫背負い＋買収の祈祷師 | 防御と回復の連携 |
| 血袋の亡者＋金歯の追い剥ぎ | HP奪還とゴールド回収 |
| 灯盗みの小鬼＋金庫背負い | エナジーを奪還して防御役を攻める |
| 灯盗みの小鬼＋血袋の亡者 | 手数とHPの奪還 |
| 贋金鋳造師＋金歯の追い剥ぎ | 攻撃役への資金供給 |
| 贋金鋳造師＋金庫背負い | 防御役への資金供給 |
| 贋金鋳造師＋買収の祈祷師 | 支援役への資金供給 |

エナジー奪取役は1編成1体まで。贋金鋳造師追加後の8候補・等確率は、文書化時点の編成案として扱う。

## 5. 強敵

基本候補は以下の3種類。候補をシャッフルして順に選び、全種類消化後に補充する案。

### 5.1 黄金鎧の傭兵長

HP135／初期所持90G。

| 順番 | 行動 |
|---|---|
| ① | 12ダメージ・30G奪取 |
| ② | 30G消費して8×3。不足なら5×3 |
| ③ | 30G消費して24ブロック。不足なら8ブロック |
| ④ | 30G消費して30ダメージ。不足なら18ダメージ |

1周期の最大供給30G・消費90G。初期資金を使い潰す設計。早期撃破で報酬を狙うか、強化行動をしのいで資金切れを待つ。贋金鋳造師との同時出現は基本編成には採用しない。採用時は別途再調整する。

### 5.2 血宴の徴税官

HP120／初期貯蔵血0。

| 順番 | 行動 |
|---|---|
| ① | 6×2 |
| ② | 貯蔵血を最大12消費し、14＋消費量のダメージ |
| ③ | 12ブロック |
| ④ | 5×3 |

- 能力「血の徴収」：攻撃で減らしたプレイヤーHPを貯蔵。
- 能力「瀉血」：貯蔵血2につき筋力＋1。端数切り捨て。現在の貯蔵血に連動し、累積加算しない。
- ②は血を先に消費し、残った血による筋力を適用する案。
- 多段攻撃では、各ヒット後に血が増え、次ヒットの筋力へ反映する案。予告には防御前の最大想定値または増加条件を明示する必要がある。

### 5.3 蓄光の収集者

HP100／初期保持エナジー0。

| 順番 | 行動 |
|---|---|
| ① | 次のプレイヤーターンのエナジーを1奪う |
| ② | 16ダメージ |
| ③ | 8＋保持エナジー×4のブロック |
| ④ | 5×3 |

能力「燐光」：1ターンの間に20ダメージを受けるたび、保持エナジーを1返却する。

- ブロックを除く実HPダメージを累計し、20・40・60…へ到達するたび発動。
- 攻撃・毒・裂傷・反撃などを含む。HP喪失はダメージとは別扱い。
- 保持量が0なら返却しない。その時点の閾値を後から再利用しない。
- プレイヤーターン開始から次のプレイヤーターン開始直前を1ターンとする実装案。開始時に累計をリセットし、端数は持ち越さない。
- 返却で保持量が減ると、③のブロック量も減少する。
- 致死ダメージ時は残存保持量を一括返却し、燐光と撃破返却を二重発動させない。

## 6. ボス：黄金卿と黄金の献納者

### 6.1 編成

| 敵 | HP | 初期資源 |
|---|---:|---|
| 黄金卿 | 320 | 60G・貯蔵血0・保持エナジー0 |
| 黄金の献納者A | 35 | 0G・生成累計0 |
| 黄金の献納者B | 35 | 0G・生成累計0 |

黄金卿撃破で勝利し、残る献納者は消失。献納者は再召喚・復活しない。片方撃破でも他方の周期は変えない。

### 6.2 黄金卿の行動

| 順番 | 行動 |
|---|---|
| ① | 12ダメージ・20G奪取 |
| ② | 40G消費して6×4。不足なら4×4 |
| ③ | 40G消費して、次のプレイヤーターンのエナジーを1奪う。不足なら10ブロック |
| ④ | 貯蔵血を最大12消費し、12＋消費量のブロック |
| ⑤ | 22＋保持エナジー×3のダメージ・20G奪取 |
| ⑥ | 攻撃なし・強化なし |

- 能力「血の徴収」を持つ。貯蔵血0なら④は12ブロック。
- 保持エナジーによる強化は⑤だけに適用。「盗んだ灯」「瀉血」「燐光」は持たない。
- ③はゴールドを先に消費して奪取予約を行う。予約後に黄金卿が死亡すれば戦闘は終了する。
- ⑥は黄金卿自身の休止行動。献納者の非供給行動とは別で、現時点では維持する。

### 6.3 黄金の献納者の行動

| 戦闘ターン | 献納者A | 献納者B |
|---|---|---|
| 奇数 | 10G生成して黄金卿へ供給 | 自身に8ブロック |
| 偶数 | 自身に8ブロック | 10G生成して黄金卿へ供給 |

- 攻撃しない。非供給ターンは待機ではなく自身へのブロック。
- 生成総額上限は各60G（仮）。上限到達後は供給予定の行動も自身に8ブロックへ置き換える。
- 生成分は黄金卿へ直接供給し、献納者には蓄積しない。
- 各献納者は通常進行なら12ターンで60G生成する。以後、奪取以外の新規供給は止まる。
- 処理順は献納者A→献納者B→黄金卿を提案。同ターンに供給した金を黄金卿が使える。
- 献納者の奇数・偶数は戦闘ターンに同期し、スタンで供給を飛ばしても周期はずらさない案。
- 通常ブロックのため、供給行動時には前の8ブロックが消える。攻撃対象を切り替える余地を作る。

### 6.4 ゴールド収支

生成上限到達前・両強化行動を実行する6ターンについての最大値。

| 献納者の生存数 | 献納者から供給 | プレイヤーから奪取 | 消費予定額 | 最大収支 |
|---|---:|---:|---:|---:|
| 2体 | 60G | 40G | 80G | ＋20G |
| 1体 | 30G | 40G | 80G | −10G |
| 0体 | 0G | 40G | 80G | −40G |

実際の奪取額はプレイヤーの所持金に依存し、資金不足で代替行動を選んだ場合は消費も減る。表は毎周期必ず同じ行動をする保証ではない。

初期60Gと献納者の供給により、プレイヤーが0Gでも初回②③の資金を用意できる。献納者を倒す攻略は、直ちに強化を解除するのではなく、将来の資金を減らす攻略になる。

黄金卿の撃破時、奪ったHPを回復し、ゴールドを共通ルールで精算する。保持エナジーも返却対象だが、勝利後に攻撃へ使う機会はない。エナジー奪還の連続行動は主に通常戦闘で体験させる。

## 8. 調整・検証項目

- 初期所持金0・少額・多額で、敵の強化頻度と追加報酬を比較する。
- ゴールド奪取はブロックで止まらない。HP防御と資金供給の阻止を混同しない予告にする。
- 基礎デッキでもエナジー奪取後に攻撃・防御が成立するか確認する。
- 燐光で返ったエナジーによって追加行動できるか、撃破返却が二重にならないか確認する。
- 瀉血の多段中の筋力変動は予告理解と被害増大を重点確認する。ヒット間更新は文書化時点の処理案。
- 血の返却がある敵への被弾を前提にしすぎず、撃破まで生存できる攻撃量にする。
- HP奪還を持つ敵・贋金鋳造師が探索全体の回復量・所持金を増やしすぎないか確認する。
- 黄金卿は本体集中・献納者1体処理・2体処理の3方針を比較し、単一方針だけが有効にならないよう調整する。
- 単体導入後の編成確率、生成上限、献納者HP35・ブロック8、黄金卿の消費40Gは初期案として検証する。
