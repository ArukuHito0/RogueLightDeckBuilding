# 自動テストプレイ：段階1

本段階はランダム合法手による1ラン自動進行のみ。段階2〜5の軸別戦略・集計は未実装。

## 構成

- `dist/ai-worker.js`：独立したWorker。受け取るのはシードのみ。プレイヤーのセーブ・所持品・進行状態へのアクセスなし。Worker専用のメモリ上保存領域と非描画のDOM互換口を用意。
- `dist/ai-config.js`：基礎デッキ10枚、上限、ゲームスクリプト順、AI版・ルール版を保持。ゲーム処理を変更した場合はrulesVersionを更新する。同一シードの保証は同一AI・ルール版の組み合わせに限る。
- `dist/ai-random.js`：シードからゲーム用と判断用の独立したPRNGを生成。
- `dist/ai-runner.js`：通常のstart / enterNode / play / endTurn / take等を呼び出す。描画とアニメーション待ちのみ省略し、カードや敵の計算は複製しない。
- `observe` は公開情報を複製・凍結して返す。山札はソート済み一覧、敵は現在の予告のみ。政策関数は観測と判断用PRNGだけを受け取る。
- `dist/ai-ui.js`：「AIテスト」タブ、実行・中止・結果・検索ログ。ログは `ashbound-ai-stage1-v1` に最大5件。通常セーブ `ashbound-v1` と別キー。

## 動作

初期デッキ：斬撃3、防御3、双剣2、応急処置2。初期HP70、遺物なし、通常ランと共通ルール。
合法手を一様ランダム抽選。ターン終了・カードスキップ・ショップ退出も合法手。パックは選択解除を繰り返さないよう未選択カードの追加と確定を選ぶ。
未知のイベント結果や開封前のパック内容を先読みしない。最大HPや所持金不足などは実ゲームの合法手チェックを使用。
終了はwin/loss。安全上限はlimit、例外はerrorとして分離。中止はWorker破棄で結果を保存しない。
実処理時間をプレイ時間として扱わない。本段階の総ターン等は確認用カウンタで、人間換算時間や思考負担の指標ではない。

## 確認方法

1. ゲームの「AIテスト」を開く。
2. シード `ashbound-1` で「1ラン実行」を押す。
3. 段階1-v1／ルールv33ではゲームオーバー、第7層、48行動、11ターンで終了。
4. 同じシードを再実行し、結果・ログ照合値・行動列が一致することを確認。
5. プレイヤーのランやコレクションはそのままで、ログからマップや戦闘の各操作を確認できる。

## 自動検証

`node tests/ai-stage1.cjs`

- 実際のworkerエントリをVMで読み込み、importScriptsとmessageプロトコルを検証。
- 同じシードの結果・全行動ログを完全一致で比較。
- 100種類のシードすべてがゲームオーバーまで到達（最深第10層）。途中の安全停止・例外なし。これは自動進行の確認であり、軸別バランスの測定ではない。
- 戦闘、宝箱、マップ、不明イベント、休息、報酬、ショップを通過。パック選択・消費アイテムの対象選択・手札選択・除外からの回収を含む。
- 山札順・敵の内部行動設定・未遭遇の強敵プールを変更しても、公開観測が変わらないことを検証。
- Workerが通常画面と同じゲームスクリプトを同じ順で読み込むことを検証。

`node tests/ai-isolation.cjs` で、UIからWorkerへ送るのがシードのみであること、実行完了・中止・ログ削除によってプレイヤーの状態と通常セーブが変化しないことも確認。

ブラウザのWorker起動・画面の見た目はこの環境では未確認。
