# ACT5 記憶の書庫（v117）

仕様の正本：dist/act5.js。ACT4クリアで解放。通常4種、強敵3編成、ボス「記録の番人」。

## 確定した補完事項

- ボスの召喚敵は同時に最大2体（ボス本体は含めない）。空き枠分だけ召喚する。
- 満杯でもHP10回復と読解解除を行う。召喚できなかった候補は抽選袋から消費しない。
- 抽選は4種の袋。一巡境界の次の2候補が同種にならないよう、新しい袋の先頭順だけを調整する。候補・袋は保存される。
- スタン中はACT5の行動周期を据え置き、読解を保持。ACT1～4の周期規則は変更しない。
- 赤墨の司書は他の生存敵を予告で指定。単独なら筋力付与を不発とし、自身へ変更しない。
- 召喚敵HPは通常の60%切り上げ（39/26/35/30）。召喚フェーズには行動しない。
- 破綻は攻撃・毒・裂傷・反撃の共通HP減少経路で死亡時1回だけ発動。番人が20HPを失う。番人死亡による消去では発動しない。
- 読解はスタック数を表示せず、有効状態として表示。ブロックと強化内容は説明に記載する。
- 非攻撃でブロックが0になった場合は読解を維持する。攻撃で正のブロックを0にした場合と明示的な全除去で解除する。

## 接続点

- combat-update.js: 敵ターンのブロック保持判定、行動前prepareAct5Action、primitive damage後onAct5Damage。
- 破綻はdealDamageのhpLossオプションでブロック無視、攻撃補正なし。afterDamage由来の効果を発火しない。
- 明示的ブロック全除去はcombat-update.js/overhaul.js/lucky.jsで読解解除に接続。
- ACT5も既存のact2行動記録方式を使うため、act2:trueを持ち、snowActionラップで付随効果を処理する。
- 不実行のスタン行動は、既存ACT2ラップのactionStep加算をACT5のみ相殺する。
- archiveId/summonerIdで召喚元を保持。死体枠の再利用時は新しい個体IDを割り当てる。
