# 遺物システム（v33）

ユーザー添付仕様に基づく実装。名称は遺物。

- カテゴリ抽選：探索30、開始終了28、戦闘15、エナジー7、ステータス12、カード8（%）。未定の19%の配分はユーザーから一任された。
- 1個目100%、2個目60%、3個目40%を順次抽選。失敗で終了（最終1/2/3効果=40/36/24%）。同じ効果を重複させない。エナジーカテゴリのみ同カテゴリも重複させない。
- 戦闘報酬の未鑑定品2/3個は各50%。強敵で1個、ボスで残り。宝箱は独立して1/2個を各50%で追加し、完走時合計3〜5個。未完走は確保済み分のみ、リタイアは持ち帰らない。
- 100個保管、持ち込み1個。遺物の効果・ラン内スタックは出発時のスナップショット。保管・鑑定・再抽選状態は既存セーブに永続化。
- 分解は1個1遺物ポイント。再抽選は1回1ポイント。候補を保存し、採否選択後も支払いを戻さない。
- 戦いの呼び声は3・6・9…ターン開始時、自身の筋力+2、生存敵全体の筋力+1。通常戦闘の強敵化は廃止。ランダムなステータスは筋力・守護・プレート・再生を等確率で1スタックずつ。
- 倍化はダメージ・ブロック以外の数値に適用。攻撃回数、条件の閾値、発動間隔は維持。HP喪失・最大HP減少も倍化。カード使用ごとにHP3喪失、コスト変更なし。
- 追加ドロー禁止は通常の戦闘／ターン開始ドロー以外を禁止。捨て札から手札への回収と生成はドローではない。
- 初期デッキに組み込まれたEPICは使用できるが、EPIC出現禁止中は新規のラン取得・生成・販売・宝箱に出現しない。
- 最大HP・現在HP+1はランのデッキへの取得時のみ。戦闘限定の生成カードでは発動しない。

主要ファイル：`dist/relics.js`。共通フック：`combatCard`、`allowedRunCard`、`addRunCard`、`draw(n, baseline)`、`gainBlock`、`onCardResolved`。

- 最初の盾は守護適用後の最初の正のカードブロック獲得量を2倍。命を削る火は最大HP20%減少。連戦の鼓舞は敵の実HPを減らすダメージ3回ごとに筋力1。
- マイセットはカード配列に加え、別メタデータで名前と遺物IDを保持。分解済み遺物は未装備として通知。

- 最新の戦闘解決は `dist/combat-update.js`。`dealDamage` と `loseHP` を分離。焼身・激昂は因果連鎖ごとに各1回発動し無限ループを防ぐ。
- トークンとコピーは負のIDを持ち、ランのbattleCardsメタデータから再構築。配列の通常要素には入らず、各取得プールから隔離。
- 回帰テスト：`node tests/combat-v31.cjs` と `node tests/reload-v31.cjs`。

- v32のショップ・宝箱は `dist/run-packs.js`。ラン内パックは基礎パックと独立。5枚から0〜2枚選択し、選択確定時に追加。抽選と課金は一度のみ。
- ショップ各6商品は1点ずつ。軸別は対象軸4倍の相対重み、通常55/35/10%、EPIC重視15/35/50%。同種3枚所持はプール外。
- 宝箱の取得量は `chestRelics` で分離し、戦闘報酬の残枠計算から除く。セーブ読み込みでも合計を3個に切り詰めない。
