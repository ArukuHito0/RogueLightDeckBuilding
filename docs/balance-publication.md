# バランス設定の反映

調整サイトの「本編に反映」で差分を確認し、確定する。公開設定は探索していない状態で本編を開いたときに読み込まれ、次に開始する探索から適用される。進行中の探索を再開すると、戦闘中に作成したカードにも探索開始時の調整値が適用される。履歴から設定を読み込んで再反映すると、過去の設定へ戻せる。

カード説明は、元の説明に対応する数値が一箇所あれば置き換える。位置を特定できない場合は、調整された効果名と値を追記する。

公開側の保存先は既存の SAVES バインディング内のバランス専用キー。調整サイトと本編のサーバーに同じ BALANCE_PUBLISH_KEY を秘密の環境変数として設定する。調整サイトはオーナー限定で運用する。

調整可能な項目を変更する場合は、worker/balance-fields.json の許可項目と範囲も同時に更新する。node scripts/build-worker.mjs の後、node tests/balance-publish.mjs で検証する。

敵の行動は行動順と効果ごとに調整する。通常遭遇の重みは同じACT・出現枠の候補の間で比較する。単体と複数が同じ枠から抽選される場合は共通の合計を使う。ACT1に単体の通常遭遇はない。

調整項目を追加した後は `node scripts/update-balance-fields.cjs` で公開APIの許可項目と出現枠の検証データを更新する。

調整サイトの「敵」タブでは、ACT・種別で絞り込み、敵ごとに最大HPと能力・行動を編集する。灰冠の王の謁見は発動HP、スタン期間、筋力を持つ。既存の調整IDは維持する。
