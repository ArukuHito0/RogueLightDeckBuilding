# ラッキー・ガール（v89）
- 初期HP77。探索技能ポーカー。独立した潜在カード52種・役5種。
- 実際の定義は dist/lucky-cards.js。処理は dist/lucky.js。
- 全ての判定は本来のコスト。コスト軽減・凍結・ミステリーコストは記録する数字を変更しない。
- ハンドは5枚で必ずリセット。役なしでもリセットし、複数成立時は1枚選択する。
- ストレートは5枚内に0〜3が各1枚以上。ツーペアは異なる数字のペア2組（3枚+2枚も成立）。Xは役ごとに数字を代用。
- 役はトークンタイプ。潜在報酬・通常生成のプールには混ぜない。保持し、使用後除外する。
- オールスリーは筋力2・守護2・3ドロー。
- フォールドは手札を効果で捨てたときのみ無料自動プレイ。使用後とターン終了時の破棄は対象外。
- 複数枚を捨てる場合、先に対象を確定して取り分け、選択順にフォールドする。対象カードは自身の処理完了まで捨て札へ置かない。
- フォールドも通常プレイとしてポーカーへ記録。役とオーファイブのプレイのみ記録しない。
- オーファイブは開始時の捨て札から対象を確定。対象を取り分け、1枚ずつ無料プレイし除外。再シャッフルで同じ対象を引き直さない。
- 自動単体攻撃は生存している敵をランダムに対象にする。
- スロットは自身のタイプと照合。見たカードを取り分け、山札が尽きたら捨て札から補充。今回見たカードは補充へ混ぜない。最後に山札へ戻してシャッフル。
- テイクワンは、その抽選で見たカードのうち現在山札にある実物から選ぶ。
- ワンモアチャンスの再抽選もスロット回数と成否のトリガーに数える。ダブルアップは成功した効果を反復し、抽選回数は増やさない。
- ストリーク2種は成功時に効果とスロット値+1を実行。個体ごとに戦闘内で保存し、最大5。
- ストリークステップは7×現在スロット値を1回のブロック獲得として処理。
- ストライクゼロの同名強化、ドロー・抽選回数、ペイアウトの成長は戦闘内。
- 通常のターン開始ドローはフォース・ドローストライクの効果ドローへ数えない。スタートアップ等による追加ドローは数える。
- マリガンは通常のターン開始ドロー後に選択。スタートアップ追加ドローと除外を先に処理する。
- ミステリーコストは各個体へそのターン中固定の0〜3を割り当てる。遺物・凍結による加算は維持する。
- 先読み・手札選択・自動プレイの未完了タスクをシリアライズし、再読み込み時に途中から再開。
- 非同期の表示演出が戦闘処理やセーブを妨げない。選択中は通常プレイ・ターン終了を停止。
- テスト: tests/lucky-v89.cjs / tests/lucky-reload-v89.cjs。
- ブラウザーの操作・描画QAは本作業環境にブラウザー制御がないため未実施。DOM代替環境による画面HTML生成・セーブ復元・戦闘ロジックを検証。
